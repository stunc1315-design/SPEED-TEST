What is an internet speed test?

An internet speed test measures the performance of your internet connection. Download speed shows how quickly data can be received from the internet, while upload speed shows how quickly data can be sent. Ping measures the response time of your connection, and jitter measures variations in that response time.

01 Stop large downloads and uploads before testing.
02 Use an Ethernet connection when possible for more consistent results.
03 Run the test at different times to compare your connection performance.
